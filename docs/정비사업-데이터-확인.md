### 해제 필드는 있다 — 그러나 대상이 다르다

`방배신동아아파트재건축`), 이는 **지구단위계획구역으로 관리되는 재건축 건**이지
도시정비법상 정비구역 지정·해제 이력이 아니다. 정비사업만 걸러내는 구분 필드는
없다 — `MCLSF`/`SCLSF`가 전부 비어 있기 때문이다.

**판정: 1순위 가설은 틀렸다.** 이력 데이터셋이 맞고 해제 기록도 남지만,
정비사업이 아니라 지구단위계획·특별계획구역 전용이다. 4번 항목에 쓸 수 없다.

### 지정/해제 구분 — `RPT_TYPE`

6,584건 전수 분포:

```

2024  신설      ← 신규 지정

  94  정정
  26  실효      ← 실효(해제의 일종)
  26  기정
```

**`MCLSF`가 6,584건 전부 `정비구역`.** 필터링이 필요 없다 — 데이터셋 전체가
정비사업이다.

`SCLSF`(사업유형) 분포:

```
2394  주택재개발사업구역        376  주택재건축사업

 437  재개발사업지구              4  결합정비구역
```

### 주의 — 레코드 단위가 "구역"이 아니라 "고시 이벤트"다

`PRJC_CD` 기준 고유 사업은 **4,069개**, 레코드 6,584건 → 사업당 평균 1.6건.
같은 구역의 신설→변경→폐지가 각각 별도 행으로 쌓인다. 따라서:

- **신규 지정** = `RPT_TYPE='신설'` 행
- **해제** = `RPT_TYPE IN ('폐지','실효')` 행
- **현재 살아있는 구역** = `PRJC_CD` 그룹에 폐지/실효 이력이 없는 것 → **3,867개**
  (폐지/실효 이력 있는 사업 202개)

### 날짜 필드가 없다

날짜 필드가 **직접 존재하지 않는다.** `RPT_MNG_CD`/`PRJC_CD` 코드 안에 8자리
날짜가 박혀 있고(`11000AGZ`**`19850403`**`2330`), 범위는 `19660118 ~ 99999999`다.
`9999`로 시작하는 미확정 코드가 18건 있다. **이 내장 날짜는 고시일과 일치한다는
보장이 없으므로 §3의 조인으로 실제 고시일을 가져와야 한다.**

### 자치구 필드가 없다

`LOGVM`은 자치구가 아니라 **결정권자**다. 5,819건이 `서울특별시`이고 자치구가
들어간 건은 765건뿐이다. 위치는 `PSTN_NM` 자유 텍스트에서 파싱해야 한다.

| 방법 | 신설·폐지 2,461건 기준 확보율 |
|---|---:|
| `PSTN_NM`에서 자치구명 정규식 추출 | 79.2% |
| + `LOGVM`이 자치구인 경우 폴백 | — |
| + `upisDraft.LOGVM_CD`를 `PRJC_CD`로 조인 | **85.5%** |

3단 폴백을 써도 **14.5%는 자치구를 특정할 수 없다**(예: `중화2동 309-39번지 일대`
— 동명만 있고 구가 없다). 법정동명 → 자치구 매핑표를 별도로 두면 대부분 메울 수
있어 보이나 이번에 검증하지 않았다.

**국토부 실거래(1유형)와 조건이 다르다.** 4유형은 두 가지를 금지한다.

- **상업적 이용금지** — 대표 블로그에 광고·제휴가 붙거나 사업 홍보 목적이면
  상업적 이용에 해당할 소지가 있다
- **변경금지** — 원 데이터를 가공·재구성해 게시하는 것이 걸린다. 대시보드는
  본질적으로 집계·시각화이므로 이 조항과 정면으로 만난다

이 판단은 법률 해석이 필요한 영역이라 **여기서 결론 내리지 않는다.** 실무적으로
가능한 경로는 셋이다.

1. 서울시에 **별도 이용 허락**을 받는다 (4유형은 저작권자 허락 시 이용 가능)
2. 이 항목을 **비영리 범위로 한정**해 게재한다
3. 정비사업 항목을 빼고 1~3번(국토부 1유형)만 게재한다

**1~3번 항목의 국토부 실거래는 영향받지 않는다.** 출처가 다르다.
